How this page is built (SQL JOIN)

An inventory row only stores pharmacy_id and medicine_id. To show the pharmacy name, the medicine name and its category together, Django JOINs pharmacy_app_inventory with pharmacy_app_pharmacy, home_app_medicine and home_app_medicinecategory using Inventory.objects.select_related('pharmacy', 'medicine', 'medicine__category').
